# Kanto region assets

These assets are imported from Bulbagarden Archives for the private portfolio project.

## Source

- Repository: https://archives.bulbagarden.net/
- Source category: Kanto maps
- Game set used for this first pass: Pokémon FireRed and LeafGreen
- Import method: MediaWiki `imageinfo` API

The application uses local copies under `assets/regions/kanto/` so the runtime does not depend on Bulbagarden being available.
