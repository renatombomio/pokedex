# Type backgrounds

Background assets used by the Pokémon detail card, one image per Pokémon type.

## File naming

- `normal.png`
- `fire.png`
- `water.png`
- `grass.png`
- `electric.png`
- `ice.png`
- `fighting.png`
- `poison.png`
- `ground.png`
- `flying.png`
- `psychic.png`
- `bug.png`
- `rock.png`
- `ghost.png`
- `dragon.png`
- `dark.png`
- `steel.png`
- `fairy.png`

Keep the filenames lowercase and use `.png` for all type backgrounds.
